Privacy Policy

MHW Prop Mail Assistant · Last updated 9 September 2026

Summary

This application is used by one person, on their own Google account, on their own computer. It is not offered to the public and it collects nothing from anyone else.

What data the application accesses

With the owner's explicit Google authorisation, the application can access:

  • Gmail — message content, subjects, senders, recipients, labels and settings in the owner's own mailbox, and the ability to create drafts and send messages from it.
  • Google Drive — file names, contents and sharing permissions in the owner's own Drive, and the ability to create and modify files there.
  • Basic profile — the email address and name of the account that granted access, used only to label which account is in use.

Where the data goes

  • The application runs locally on the owner's computer. It has no server of its own, no database, and no hosted backend.
  • Data is requested from Google's APIs only when the owner asks for it, and is held in memory for the duration of that request.
  • To produce an answer, the content the owner asks about is sent to the AI assistant the owner is using, and is handled under that provider's own privacy terms. This is the ordinary consequence of asking an AI assistant to read or write mail, and it is the only place the data goes.
  • No data is sold, rented, shared with advertisers, or transferred to any other third party.
  • There is no analytics, no telemetry and no tracking in this application, and this website sets no cookies.

Storage and retention

The application stores an OAuth token on the owner's own computer so it does not have to ask for permission on every use. The token is kept in the owner's user account with file permissions restricting it to that user. No message content, file content or personal data is written to any store by the application, and nothing is retained after a request completes.

Use of Google user data

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the features the owner directly requests. It is never used for advertising, never sold, and never used to build profiles.

Withdrawing access

Access can be revoked at any time from Google Account permissions. Revoking access immediately stops the application from reading or sending anything. Deleting the stored token file from the computer has the same effect locally.
